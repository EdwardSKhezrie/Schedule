# Schedule

A standalone daily schedule app. Weekday, Sunday and Shabbat checklists,
the 30-day Tehillim cycle, the parasha for each Shabbat, and occasions by date.

Day / Week / Month views. Taps save in the browser, so install it to the
home screen and use it from there.

`events.json` holds occasions by date (`YYYY-MM-DD`). Occasions added in the
app itself are kept on the device only.
